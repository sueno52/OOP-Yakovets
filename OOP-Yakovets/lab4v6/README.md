# Лабораторна робота №4: Наслідування та Поліморфізм

* **Тема:** Наслідування. Ключові слова `base`, `override`, `virtual`. Приховування членів (`new`)
* **Варіант:** №6 (`MediaItem` → `BookMedia` → `MovieMedia`)


## Мета роботи
Опанувати створення ієрархій класів, застосування `base`, `virtual`, `override` для поліморфізму та використання модифікатора `new` для приховування методів.


##  Хід роботи

1. **Створення проєкту:** Створено консольний проєкт за допомогою CLI-команди `dotnet new console -o OOP-Yakovets/lab6v6`.
2. **Базовий клас `MediaItem`:** Реалізовано приватні поля `_title`, `_duration`, публічні властивості, конструктор, віртуальний метод `virtual void Play()` та метод `string GetMediaType()`.
3. **Похідні класи `BookMedia` та `MovieMedia`:**
   * Створено конструктори з викликом `base(...)`.
   * Перевизначено віртуальний метод через `override void Play()`.
   * Додано унікальні методи `ReadSample()` та `ShowTrailer()`.
   * У класі `BookMedia` реалізовано приховування методу за допомогою `new string GetMediaType()`.
4. **Демонстрація в `Main`:** 
   * Викликано унікальні методи об'єктів.
   * Продемонстровано поліморфізм через масив `MediaItem[]`.
   * Показано різницю між `override` та `new` при виклику через посилання базового та похідного типів.
