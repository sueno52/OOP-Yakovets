# Лабораторна робота №4: Наслідування та Поліморфізм

* **Тема:** Наслідування. Ключові слова `base`, `override`, `virtual`. Приховування членів (`new`)
* **Варіант:** №6 (`MediaItem` → `BookMedia` → `MovieMedia`)


## Мета роботи
Опанувати створення ієрархій класів, застосування `base`, `virtual`, `override` для поліморфізму та використання модифікатора `new` для приховування методів.


##  Хід роботи

1. **Створення проєкту:** Створено консольний проєкт за допомогою CLI-команди `dotnet new console -o OOP-Yakovets/lab6v6`[cite: 1].
2. **Базовий клас `MediaItem`:** Реалізовано приватні поля `_title`, `_duration`, публічні властивості, конструктор, віртуальний метод `virtual void Play()` та метод `string GetMediaType()`[cite: 1].
3. **Похідні класи `BookMedia` та `MovieMedia`:**
   * Створено конструктори з викликом `base(...)`[cite: 1].
   * Перевизначено віртуальний метод через `override void Play()`[cite: 1].
   * Додано унікальні методи `ReadSample()` та `ShowTrailer()`[cite: 1].
   * У класі `BookMedia` реалізовано приховування методу за допомогою `new string GetMediaType()`[cite: 1].
4. **Демонстрація в `Main`:** 
   * Викликано унікальні методи об'єктів[cite: 1].
   * Продемонстровано поліморфізм через масив `MediaItem[]`[cite: 1].
   * Показано різницю між `override` та `new` при виклику через посилання базового та похідного типів[cite: 1].
