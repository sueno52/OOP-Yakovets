# Лабораторна робота №5: Поліморфізм (Динамічне зв’язування)

* **Тема:** Поліморфізм: динамічне зв’язування та перевизначення методів
* **Варіант:** №6 (`Dish` → `Pizza`, `Soup`, `Salad`)


##  Мета роботи
Навчитися реалізовувати поліморфну поведінку за допомогою віртуальних методів (`virtual`) та їх перевизначення (`override`), а також агрегувати результати поліморфних викликів.

##  Хід роботи

1. **Створення проєкту:** Створено новий консольний проєкт `lab8v6` у директорії `OOP-Yakovets`.
2. **Ієрархія класів:**
   * **`Dish` (базовий клас):** містить властивість `Name`, конструктор та віртуальний метод `virtual void Prepare()`.
   * **`Pizza` (похідний клас):** додає властивість `Toppings` та перевизначає метод `override void Prepare()`[cite: 1].
   * **`Soup` (похідний клас):** додає властивість `BrothType` та перевизначає метод `override void Prepare()`[cite: 1].
   * **`Salad` (похідний клас):** додає властивість `Dressing` та перевизначає метод `override void Prepare()`[cite: 1].
3. **Демонстрація поліморфізму та агрегація в `Main`:**
   * Створено колекцію `List<Dish>`, у яку додано об'єкти `Pizza`, `Soup` та `Salad`[cite: 1].
   * У циклі `foreach` виконано виклики `Prepare()`, що продемонструвало динамічне зв'язування[cite: 1].
   * Виконано агрегацію: зібрано підсумковий список усіх приготованих страв та пораховано їх кількість[cite: 1].
