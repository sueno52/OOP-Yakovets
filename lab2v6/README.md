# Лабораторна робота №2
**Тема:** Клас із кількома конструкторами. Життєвий цикл об’єкта.  
**Варіант:** №6 (Клас `BankAccount`)   

---

## Мета роботи
Навчитися реалізовувати перевантажені конструктори, дослідити порядок їх викликів за допомогою ключового слова `: this()` та зрозуміти основи життєвого циклу об’єкта в C# (створення, використання, знищення за допомогою Garbage Collector).

---

## Опис реалізації

У межах лабораторної роботи було реалізовано клас `BankAccount`, який містить:

- **Приватні поля:**
  - `_owner` (string) — власник рахунку.
  - `_accountNumber` (string) — номер рахунку.
  - `_balance` (decimal) — баланс рахунку.
- **Публічні властивості (тощо тільки для читання зовні):**
  - `Owner`, `AccountNumber`, `Balance`.
- **Перевантажені конструктори:**
  - `BankAccount(string owner, string accountNumber, decimal initialBalance)` — основний параметризований конструктор із валідацією початкового балансу.
  - `BankAccount(string owner, string accountNumber)` — конструктор, який викликає основний за допомогою `: this(owner, accountNumber, 0m)` із дефолтним балансом `0`.
- **Методи:**
  - `Deposit(decimal amount)` — внесення коштів із валідацією суми.
  - `Withdraw(decimal amount)` — зняття коштів із перевіркою наявності необхідної суми на балансі.
- **Деструктор (Фіналізатор):**
  - `~BankAccount()` — виводить повідомлення у консоль про видалення об'єкта з пам'яті під час збору сміття.
