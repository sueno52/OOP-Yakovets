# Лабораторна робота №3
**Тема:** Життєвий цикл об’єкта та керування ресурсами.  
**Варіант:** №6 (`AudioPlayer`)  
## Мета роботи:
Поглибити розуміння життєвого циклу об’єкта в C#, навчитися працювати з некерованими ресурсами, реалізувати інтерфейс `IDisposable` та патерн Dispose.
### Хід роботи

1. **Створення консольного проєкту**
   * За допомогою CLI інструменту `.NET SDK` у терміналі створено новий консольний проєкт `lab3v6` за допомогою команди:
     ```bash
     dotnet new console -o OOP-Yakovets/lab3v6
     ```

2. **Проєктування класу відповідно до Варіанту 6 (`AudioPlayer`)**
   * Створено клас `AudioPlayer`, що реалізує інтерфейс `IDisposable`.
   * Додано приватні поля для імітації керованих та некерованих ресурсів (`_trackName`, `_isPlaying`, `_disposed`).
   * Реалізовано конструктор, що ініціалізує початковий стан і "виділяє ресурс", а також допоміжні методи `Play()` та `Stop()`.

3. **Реалізація патерну Dispose**
   * Реалізовано захищений віртуальний метод `Dispose(bool disposing)` для роздільного очищення ресурсів:
     * При `disposing == true`: звільнення керованих ресурсів.
     * Незалежно від `disposing`: звільнення некерованих ресурсів та встановлення прапорця `_disposed = true`.
   * Реалізовано публічний метод `Dispose()`, який викликає `Dispose(true)` та пригнічує фіналізацію через `GC.SuppressFinalize(this)`.
   * Додано деструктор (фіналізатор) `~AudioPlayer()`, який викликає `Dispose(false)` на випадок, якщо об'єкт не було закрито явно.

4. **Демонстрація трьох сценаріїв у методі `Main`**
   * **Випадок 1:** Використання об'єкта через блок `using` з автоматичним викликом `Dispose()`.
   * **Випадок 2:** Створення об'єкта з явним викликом `player.Dispose()` без застосування `using`.
   * **Випадок 3:** Створення об'єкта без виклику `Dispose()` з подальшим викликом `GC.Collect()` та `GC.WaitForPendingFinalizers()` для демонстрації спрацьовування деструктора.
