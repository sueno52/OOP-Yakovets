# Лабораторна робота №6

* **Тема:** 
Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

##  Мета роботи: ##
Навчитися створювати ієрархії класів, використовувати base, virtual, override для реалізації поліморфізму та розуміти відмінність між override і приховуванням через new.

## Хід роботи

1. **Створено консольний проєкт:** `dotnet new console -o OOP-Yakovets/lab6v6`
2. **Ієрархія класів:**
   * **`MediaItem` (базовий клас):** містить приватні поля `_title`, `_duration`, властивості `Title`, `Duration`, конструктор, віртуальний метод `virtual void Play()` та звичайний метод `string GetMediaType()`.
   * **`BookMedia` (похідний клас):** додає властивість `Author`, викликає конструктор через `base(...)`, перевизначає метод `override void Play()` та має власний метод `ReadSample()`.
   * **`MovieMedia` (похідний клас):** додає властивість `Director`, викликає конструктор через `base(...)`, перевизначає метод `override void Play()` та має власний метод `ShowTrailer()`.
3. **Демонстрація приховування через `new`:**
   * У `BookMedia` створено метод `new string GetMediaType()`, який приховує однойменний метод `MediaItem`.
4. **Демонстрація поліморфізму в `Main`:**
   * Створено колекцію `List<MediaItem>`, у яку додано об'єкти `MediaItem`, `BookMedia` та `MovieMedia`.
   * У циклі `foreach` виконано виклики `Play()`, що продемонструвало динамічне зв'язування.
   * Виклик `GetMediaType()` через посилання `MediaItem` та `BookMedia` показав різницю між `override` і `new`.
