# Лабораторна робота №6

* **Тема:** 
Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

##  Мета роботи: ##
Навчитися створювати ієрархії класів, використовувати base, virtual, override для реалізації поліморфізму та розуміти відмінність між override і приховуванням через new.

## Хід роботи

1. **Створено консольний проєкт:** `dotnet new console -o OOP-Yakovets/lab6v6`
2. **Ієрархія класів:**
   * **`MediaItem` (базовий клас):** містить приватні поля `_title`, `_duration`, властивості `Title`, `Duration`, конструктор, віртуальний метод `virtual void Play()` та звичайний метод `string GetMediaType()`.
   * **`BookMedia` (похідний клас):** додає властивість `Author`, викликає конструктор через `base(...)`, перевизначає метод `override void Play()` та має власний метод `ReadSample()`.
   * **`MovieMedia` (похідний клас):** додає властивість `Director`, викликає конструктор через `base(...)`, перевизначає метод `override void Play()` та має власний метод `ShowTrailer()`.
3. **Демонстрація приховування через `new`:**
   * У `BookMedia` створено метод `new string GetMediaType()`, який приховує однойменний метод `MediaItem`.
4. **Демонстрація поліморфізму в `Main`:**
   * Створено колекцію `List<MediaItem>`, у яку додано об'єкти `MediaItem`, `BookMedia` та `MovieMedia`.
   * У циклі `foreach` виконано виклики `Play()`, що продемонструвало динамічне зв'язування.
   * Виклик `GetMediaType()` через посилання `MediaItem` та `BookMedia` показав різницю між `override` і `new`.

## Контрольні запитання

1. **Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.**
   * Наслідування дозволяє створити новий (похідний) клас на основі існуючого (базового). Похідний клас отримує поля, властивості й методи базового і може додавати власні або змінювати успадковані.
   * Між класами виникає зв'язок **«є-різновидом»** (*is-a*).
   * **Приклад:** книга і фільм є різновидами медіа. Тому `BookMedia` і `MovieMedia` успадковують від `MediaItem` спільні `Title` та `Duration`, але кожен має свої властивості (`Author`, `Director`).

2. **Для чого використовується ключове слово `base`? Наведіть приклади його застосування.**
   * `base` дає доступ до членів базового класу з похідного.
   * **Виклик конструктора базового класу:** `public BookMedia(string title, int duration, string author) : base(title, duration)`.
   * **Виклик методу базового класу:** `base.Play()` всередині перевизначеного методу, коли треба розширити, а не повністю замінити поведінку.

3. **У чому полягає різниця між `virtual` та `override`? Як вони забезпечують поліморфізм?**
   * **`virtual`** ставиться в базовому класі й дозволяє похідним класам перевизначити метод (`public virtual void Play()`).
   * **`override`** ставиться в похідному класі й надає нову реалізацію віртуального методу (`public override void Play()`).
   * Разом вони забезпечують **динамічне зв'язування**: метод обирається під час виконання за фактичним типом об'єкта. Тому в циклі `foreach (MediaItem item in library)` виклик `item.Play()` для кожного об'єкта виконує свою версію методу.

4. **Коли варто використовувати модифікатор `new` для приховування члена базового класу, і які наслідки це має?**
   * `new` використовують, коли свідомо потрібно приховати **невіртуальний** метод базового класу, наприклад якщо базовий клас не можна змінити.
   * **Наслідок:** статичне зв'язування. Метод обирається за **типом посилання**, а не за типом об'єкта.
   * У роботі `bookAsBase.GetMediaType()` (посилання `MediaItem`) повертає «Медіа», а `book.GetMediaType()` (посилання `BookMedia`) — «Книга».
   * Через це `new` може спричинити неочікувану поведінку, тому для поліморфізму краще використовувати `virtual` / `override`.
